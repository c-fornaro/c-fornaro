Scratch · Interactive music project

Low Battery 2.0

An expanded version of my first Scratch project. This version turns the original drum kit into a larger interactive music environment, adding new instruments, singers, characters, different scenes and more ways for the player to interact with the project.

The project includes a drum kit, three guitars, a keyboard, a bell and two singers, as well as a background character that changes direction while walking. The original three background songs were expanded to eight, controlled through a song counter that changes with the SPACE key.

I also created Custom Blocks to organize repeated behaviors and make the project easier to manage. The game now includes an introduction from a character who presents himself as the supervisor, giving the environment more context and encouraging the player to explore and interact with it.

Scratch · Interactive project

Low Battery

My first interactive music project made with Scratch. The player can play four different drum sounds using the keyboard, switch between three background music tracks and interact with an animal that reacts when the mouse cursor gets close to it.

This project was an introduction to combining programming concepts with sound, animation and user interaction. It became the starting point for Low Battery 2.0.
